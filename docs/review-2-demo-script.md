# WasteVoice AI — Review 2 Demo Script

## 1. Reporter Login

- Sign in with the Reporter test account.
- Show role-aware routing into the Reporter dashboard.

## 2. Create Report

- Open New Report.
- Enter a natural-language observation.
- Explain that the user is reporting an observed condition rather than asking AI to make an operational decision.

## 3. AI Assist

- Open AI Assist.
- Enter location and description.
- Run the assistant.
- Show category, summary and missing-field suggestions.
- Explain that the result is advisory.

## 4. Human Confirmation

- Review the suggestion.
- Correct the suggestion if necessary.
- Continue to the normal report form.
- Explain that the Reporter remains responsible for the factual content.

## 5. Before Evidence

- Upload the genuine before-cleaning image used for the demonstration.
- Confirm it is associated with the report.

## 6. Submit

- Submit the report.
- Show Submitted status.

## 7. Authority

- Log in as Authority.
- Open the new report.
- Review the description and evidence.

## 8. Assign Staff

- Select Staff.
- Submit the protected assignment operation.
- Show Assigned status.

## 9. Staff

- Log in as Staff.
- Open the assigned task.
- Start cleaning.
- Upload after-cleaning evidence.
- Submit for authority verification.

## 10. Authority Verification

- Return to Authority.
- Open the verification workspace.
- Compare before/after evidence.
- Approve or request correction.

## 11. Resolved

- Show that only authority approval moves the report to Resolved.
